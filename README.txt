仕様
外見ガチャは6項目を独立に抽選します。服装の組み合わせは自由にアレンジできます。
ふたりは恋愛に限定せず、推しカプは恋愛寄り。二人の性格は生成しません。関係性を変えたくないときは固定できます。空欄の名前はA/Bです。
Xでは結果・ハッシュタグ・公開URLを投稿編集画面に渡します。画像は保存して添付、または対応アプリへ共有できます。外見結果は全項目を載せるため縦長の画像です。
新しいガチャには自動課金や外部APIはありません。入力した名前は履歴へ保存されますが、共有操作以外で外部へ送信しません。
記事本文は変更していません。Amazonリンクはまだ通常の検索リンクです。
